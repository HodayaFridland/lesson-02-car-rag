# מערכת RAG לחברת הרכב "אופק רכב"

מערכת שעונה על שאלות של לקוחות מתוך מסמכי החברה: מפרט טכני לכל דגם, מחירון, אחריות, טיפולים, קודי התרעה וקריאות שירות. התשובות נכתבות על ידי Claude, וכל ציטוט בהן נבדק מול הטקסט המקורי.

החברה והנתונים דמיוניים, ונכתבו לצורך התרגיל.

**הדוח המלא, עם האבחון וההסברים: [REPORT.md](REPORT.md)**

## תוצאות

המערכת שופרה שלב אחרי שלב, ובכל שלב נמדדו 13 שאלות בדיקה שיש להן תשובה בנתונים. recall@3 סופר בכמה שאלות התשובה נמצאה בשלושת הקטעים הראשונים. MRR מתגמל גם על כך שהתשובה נמצאה גבוה ברשימה.

| גרסה | מה נוסף | recall@3 | MRR |
|---|---|---|---|
| בסיס | חיתוך קבוע לפי מספר תווים, וחיפוש לפי משמעות | 6/13 | 0.37 |
| חיתוך | קטע לכל כותרת, עם שם המסמך ושם הסעיף | 9/13 | 0.65 |
| היברידי | איחוד של חיפוש לפי משמעות וחיפוש לפי מילים (BM25) | 9/13 | 0.69 |
| מטא־דאטה | סינון מסמכים שהוחלפו בגרסה חדשה | 11/13 | 0.76 |

במדידת התשובות עם Claude עברו 13 מתוך 15 שאלות.

באחזור נשארו שתי שאלות שנכשלות:

- **שאלה 5:** המסמך על הרכב המסחרי הוא PDF סרוק שהטקסט שלו לא חולץ. המערכת אומרת שאין לה מידע, ולא ממציאה תשובה. התיקון הוא OCR.
- **שאלה 12:** השאלה צריכה נתונים משני מסמכים, והם לא חוזרים בשלושת הקטעים הראשונים.

## איך זה עובד

1. [`rag/loader.py`](rag/loader.py) טוען את המסמכים מהתיקייה [`data/`](data) ואת המטא־דאטה שלהם.
2. [`rag/chunking.py`](rag/chunking.py) מחלק כל מסמך לקטעים.
3. [`rag/embed.py`](rag/embed.py) הופך טקסט לווקטורים, ושומר אותם בקאש מקומי.
4. [`rag/search.py`](rag/search.py) מחפש לפי משמעות ולפי מילים, מאחד את התוצאות ומסנן מסמכים ישנים.
5. [`rag/answer.py`](rag/answer.py) שולח את הקטעים ל־Claude ומאמת את הציטוטים בתשובה.

הפונקציות שנכתבו בתרגיל הן `chunk_by_headings`, `rrf`, `is_current` ו־`verify_citations`. שאלות הבדיקה נמצאות ב־[`golden.json`](golden.json).

## הרצה

נדרש Python 3.10 ומעלה.

```
pip install -r requirements.txt
```

מדידת האחזור היא בחינם, בלי קריאה ל־Claude. כל שורה מודדת גרסה אחרת:

```
python eval_retrieval.py
python eval_retrieval.py --chunker headings
python eval_retrieval.py --chunker headings --mode hybrid
python eval_retrieval.py --chunker headings --mode hybrid --current-only
```

בהרצה הראשונה המודל יורד למחשב ומחשב וקטורים, וזה לוקח כמה דקות. הקאש `.cache/` לא נכלל במאגר.

מדידת התשובות קוראת ל־Claude ועולה בערך סנט אחד:

```
$env:ANTHROPIC_API_KEY = "..."      # Windows
export ANTHROPIC_API_KEY="..."      # Mac / Linux
python eval_answers.py --chunker headings --mode hybrid --current-only
```

המפתחות מוגדרים רק כמשתני סביבה בטרמינל, ולא נכנסים לקוד או ל־git.

## וקטורים

ברירת המחדל היא המודל `intfloat/multilingual-e5-small`, שרץ על המחשב בחינם ותומך בעברית. אפשר במקומו להשתמש ב־Voyage AI: מתקינים `voyageai`, ומגדירים את משתני הסביבה `EMBED_BACKEND=voyage` ו־`VOYAGE_API_KEY`.
